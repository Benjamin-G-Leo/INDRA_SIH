# INDRA_SIH
INDRA - India's National Disaster Risk Analysis Platform | Detects weather disasters, Verifies it using Media and immediately alerts emergency services


## Folders
- `dashboard_prototype_1/` - Next.js dashboard (mock data for now)
- `weather_platform/` - first version of the data pipeline (kept as it was)
- `weather_platform_v2/` - improved pipeline: more realistic synthetic data, fixed evaluation, ML hazard classifier (see its README)
